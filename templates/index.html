打开图片目录

选择本机文件夹后，加载其中所有图片和已有 YOLO 标签，直接在该目录标注，无需复制图片。可勾选包含子目录。

切换后，新标签按原有规则保存在所选图片目录中；视频抽帧和导出也使用该工作目录。服务重启后可再次在这里打开目录。

选择文件夹

点击磁盘或子目录浏览，选好后点击“选择此目录”。也可以直接输入完整目录路径。

导入视频并筛选标注帧

填写本机视频文件或目录，每行一个；目录会包含子目录的视频。使用本机路径无需复制原视频。

候选帧与上一张保留帧比较，三项差异均低于上限时才跳过。上限越小，保留越多。小鸟姿态变化可降低阈值或关闭去重；筛选不能保证保留所有有用变化。

抽帧不会修改原视频。已提取帧和标注会保留在工作目录。

导出已保存的标注图片集

包含已保存的原图、视频帧和对应 YOLO TXT；未保存的帧不会进入图片集。导出图片保留原始分辨率，不含绘制的框。

默认导出 images/、labels/ 和来源清单，暂不划分。勾选后生成标准 train/val 目录与 data.yaml；同一视频的全部帧只进入一个分区，至少需要两个独立来源。

配置视觉大模型 API

支持兼容 OpenAI 的图片请求。填写 API 服务地址、视觉模型 ID 和你自己的 Key；测试会发送一张程序生成的白色图片，可能产生少量 API 用量。

高级设置

API 地址与模型设置会保存在当前工作目录。Key 不写入文件、不回传浏览器、不进入导出数据。图像会按所设尺寸等比缩放，标注坐标仍对应整张原图。
